# Antonella Papelería Creativa

Sitio web estático listo para publicar en GitHub Pages o cualquier servidor estático.

## Contenido

- `index.html` - página principal
- `css/estilo.css` - estilos responsivos
- `js/scripts.js` - lógica del carrito y WhatsApp
- `img/` - activos de imágenes

## Instrucciones

1. Subir el proyecto a un repositorio de GitHub.
2. Habilitar GitHub Pages desde la configuración del repositorio.
3. Seleccionar la rama principal (`main` o `master`) y la carpeta raíz o `/docs`.

## Notas

- El sitio ya está responsive para distintas pantallas.
- Los enlaces de WhatsApp y redes sociales están configurados.
